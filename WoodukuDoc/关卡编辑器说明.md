# Wooduku 关卡编辑器说明

## 打开方式

Unity 菜单：**自定义窗口 → Wooduku 关卡编辑器**

代码目录：`WoodukuClient/Assets/Editor/WoodukuLevelEditor/`

## 功能

1. **边长 N**：输入 N，棋盘为 N×N。
2. **颜色存档**：`WoodukuColorPalette` ScriptableObject（默认 `Assets/GameRes/WoodukuLevels/WoodukuColorPalette.asset`）。
   - 每种颜色可改名、改色、勾选「开」。
   - 关闭的颜色不能涂色，也不参与导出。
   - **已开启颜色数必须等于 N**。
3. **格子标定**：选中画笔后在棋盘左键涂色 / 拖拽连涂；右键清除。
4. **检测固有解**：校验四连通色块 + 搜索解；**恰好 1 组解**视为固有解。
   - 规则：每色一猫、每行每列一猫、八邻不接触。
5. **导出 JSON**：默认 `Assets/GameRes/WoodukuLevels/level_XXX.json`。

## JSON 字段

| 字段 | 含义 |
|------|------|
| `id` | 关卡 ID |
| `size` | 边长 N |
| `hintCount` | 本关提示次数 |
| `hasUniqueSolution` | 是否固有解 |
| `solutionCount` | 检测到的解数量（最多记到 2） |
| `colors` | 逻辑色 0..N-1 的 name/hex |
| `regions` | 长度 N×N，row-major，值为逻辑色 id |
| `solutionCols` | 长度 N，`solutionCols[r]` = 第 r 行猫所在列 |
| `solutionCells` | `[{r,c}, ...]` 与上等价 |

坐标：行/列均为 `0..N-1`。
